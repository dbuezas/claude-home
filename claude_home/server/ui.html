Settings

Changes apply to the next request. No restart needed. To change the Claude token, use the add-on's Configuration tab.

Access levels

Claude must ask for a level first. Your very next message must contain the phrase. Then the level stays unlocked for the rest of the conversation. Said at any other time, the phrase does nothing. The add-on checks it in your words only, never in anything Claude writes.
1unlock protected entitiescontrol protected devices, rename things, areas, Claude's own instructions, the protected list
2unlock full accesscommands, internet, all of Home Assistant, Remote Control
3unlock supervisoralso add-ons, backups, updates, the host

Remote Control

With level 2 unlocked ("unlock full access"), Claude can start Remote Control. Then a machine called "Home Assistant" shows up in the Claude app and on claude.ai/code. Remote Control needs a one-time login to your Claude account here; the token from the Configuration tab can't do it.

Protected devices

Claude can read every device. To control a protected device, Claude needs level 1 ("unlock protected entities") first. Protected devices are hidden from Assist, so the normal Assist commands can't control them either.
