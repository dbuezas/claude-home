Changes that need a passcode

With a passcode set, Claude can propose changes. It first shows exactly what will change. Nothing happens until your next message contains the passcode. The passcode is not a secret: it proves the "yes" came from you. The add-on checks it in your message only, never in anything Claude writes. Any other reply cancels the change. Remote Claude Code can't use passcodes.
